# PC・スマホ実践アプリ

「分からなくても、画面を観察し、小さく試し、必要なら戻して自分で進める」力を育てる、デジタル初心者向けの体験型Web教材です。

Windows、Mac、iPhone、Androidを模した安全な練習環境で、実データや外部サービスへ影響を与えずに操作できます。アカウント登録、外部API、実際の送信・発信・撮影は行いません。

## 学習設計

- 4つの利用環境：Windows、Mac、iPhone、Android
- 8エリア × 4ミッション＝全32ミッション
- 7つの横断能力：観察、操作、文字、情報、管理、安全、問題解決
- 前半は「見本あり」、中盤は「手掛かり中心」、後半は「自力チャレンジ」
- 操作順ではなく、最終状態と学習証拠で完了を判定
- ヒントは方向 → 機能名 → 環境別の具体操作の3段階
- 誤操作を減点せず、安全にやり直した過程も記録

8つの学習エリアは次のとおりです。

1. 触る・動かす
2. 画面とアプリを行き来する
3. 文字を扱う
4. 検索して確かめる
5. ファイルと写真を扱う
6. 安全に進める
7. 困ったときに解決する
8. 自力で組み合わせて解く

## 実機に寄せた画面再現

練習画面は、実機を見たときにそのまま探せるよう、次の点を本物に合わせています。

- Windows 11：中央寄せタスクバー、スタート メニュー、システム トレイ、`―`/`□`/`×` のウィンドウ ボタン、Microsoft Edge、エクスプローラー、メモ帳、設定
- macOS：メニューバー（アプリ名が太字で切り替わる）、赤・黄・緑の信号機ボタン、Dock と起動中インジケータ、Finder、Safari、テキストエディット、システム設定
- iOS：Dynamic Island とステータスバー、スクイクル アイコンのホーム画面、Dock、ホームインジケータ（上スワイプでホーム、横スワイプでアプリ切替、大きく上スワイプで App スイッチャー）、コントロールセンター、Safari の下部アドレスバー
- Android：ステータスバー、Google 検索ウィジェット、アプリ一覧（ドロワー）、通知とクイック設定、`◁ ○ □` のナビゲーション バー、Chrome、Files、Keep メモ、設定

アプリ名は実機と同じ表記（Microsoft Edge / Safari / Chrome、メモ帳 / テキストエディット / メモ / Keep メモ）を使い、案内文もその名前で説明します。

## フリープレイ（自由モード）

`/free-play` から、課題のない自由モードに入れます。4つの機器を切り替えながら、ブラウザ、ファイル、設定、メール、写真、電卓、カメラ、電話などを好きなだけ試せます。押した回数と直前の変化が画面上部に出て、「最初の状態に戻す」でいつでもやり直せます。実際の送信・購入・削除は行いません。

## デジタルの「分かりやすさ」チェック

`/digital-check` では、25問の固定質問候補から回答に合う9〜11問だけを出し、ChatGPTのカスタム指示へ追加できる短い項目を作ります。外部APIやAI生成は使わず、各回答に対応する固定の文章部品を端末内で組み合わせます。

- 最初の回答と途中の理解度に応じて次の質問が変わる適応式チェック
- 用語、手順、画面移動、文字入力、ファイル、安全、復旧、ChatGPT操作の8項目を確認
- 生成される項目は約300〜500文字で、既存のカスタム指示を圧迫しにくい構成
- PC版・スマホアプリ版それぞれ3枚の日本語スクリーンショット付き登録案内
- 結果のコピーと回答のやり直しに対応。チェックの回答は保存せず、ページを開くたび説明画面から開始

## 実践環境

- クリック、ダブルクリック、右クリック、長押し、スクロール、ドラッグ
- アプリの起動・終了・切替、戻る、メニュー発見
- 文字入力、範囲選択、コピー・貼り付け、編集の取り消し
- 検索語の改善、タブ比較、発信元・更新日の確認
- ダウンロード、保存場所、名前変更、移動、添付前レビュー
- 権限判断、アカウント復旧、確認画面、怪しいメッセージ
- エラー読解、Wi-Fi切り分け、公式ヘルプ検索、代替手段
- 電話・カメラを含む、スマートフォン向けの安全な自由練習

最終4ミッションでは、答えの手順ボタンを表示せず、検索欄、ファイル名・保存場所、設定内検索とスライダー、原因選択と権限設定を実際に操作して解決します。

## 主な画面

- `/free-play`・`/free-play/[device]`：課題なしで4機器を自由に試すフリープレイ
- `/digital-check`：自分に合うデジタル説明と、ChatGPTカスタム指示への登録案内
- `/start`：環境と操作方法の選択
- `/journey/[environment]`：32ミッションの学習地図
- `/mission/[environment]/[missionId]`：目的確認 → 準備 → 実践 → 証拠確認
- `/practice/[environment]`：課題なしの自由練習
- `/progress`：完了数、能力別の証拠、ヒント・復旧状況
- `/toolbox`：困ったときの確認方法
- `/settings`：文字サイズ、コントラスト、動きの軽減、記録削除

旧URLの14ステージは、内容に対応する新ミッションへ転送します。

## 技術構成

- Next.js 16（App Router）
- React 19
- TypeScript
- CSS（外部UIライブラリ不使用）
- Local Storage（進捗・表示設定の端末内保存）

主要な実装は以下です。

```text
src/
├─ app/                      # 画面とルート
├─ content/journey.ts        # 8エリア・32ミッションの定義
├─ features/journey/         # 開始、地図、エリア、ミッション、自由練習
├─ features/os/              # Windows/macOS/iOS/Android の再現シェルとアプリ画面
├─ features/lab/             # 8種類の実践ワークスペースと状態判定
├─ features/progress/        # 学習証拠・進捗・設定の保存
└─ lib/journey-types.ts      # カリキュラムと成功条件の型
```

調査根拠、現行版の課題、カリキュラム、環境別操作、UI/UX、実装方針の詳細は [`docs/RESEARCH_AND_REDESIGN.md`](docs/RESEARCH_AND_REDESIGN.md) にまとめています。

## ローカル実行と検証

Node.js 20.9以降で実行します。

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。

```bash
npm run lint
npx tsc --noEmit
npm run build
```

本番ビルドでは、4環境 × 32ミッションを含む全220ページを生成します。公開前にはデスクトップ・スマートフォン幅、キーボード操作、主要ミッションの完了、進捗保存、JavaScriptエラーを実ブラウザで確認します。

## 保存とプライバシー

氏名やメールアドレスは保存しません。完了ミッション、能力の証拠、ヒント段階、復旧回数、自由練習、表示設定だけを現在のブラウザ内へ保存します。分かりやすさチェックの回答は保存せず、別端末への同期も行いません。
